# 홍콩·마카오 여행 플래너

개인 여행용 정적 웹 앱입니다. 빌드나 서버 계정 없이 HTML/CSS/JavaScript로 작동합니다.

## 사용

기존 정적 호스팅에 `index.html`, `styles.css`, `data.js`, `planner.js`, `app.js`를 함께 올립니다. 로컬에서는 이 폴더에서 `python3 -m http.server 8765`를 실행하고 `http://localhost:8765`를 엽니다.

화면은 지도가 바탕이고, 폰에서는 아래 시트와 탭 4개(오늘 · 일정 · 찾기 · 더보기), PC(901px 이상)에서는 왼쪽 일정 패널과 찾기 창이 지도 위에 뜹니다.

- **오늘**: 여행 기간에는 시작일과 오늘 날짜로 오늘이 며칠째인지 골라 엽니다(기간 밖이면 마지막에 본 날). 다음 장소, 내 위치에서 길찾기(출발지 없이 지도 앱을 열어 현재 위치에서 출발), 다녀왔어요(되돌리기 가능), 진행 막대, 근처 갈 만한 곳, 남은 일정, 접힌 다녀온 곳.
- **일정**: 날짜별 장소 순서(손잡이를 끌거나 ↑↓), 시간·머무는 시간·메모, 다른 날로 옮기기, 빼기, 방문 체크, 구간 이동수단·길찾기, 숙소·하루 제목, 숙소로 돌아가기, 장소 직접 추가, 되돌리기(30단계).
- **찾기**: 검색, 분류(근처·지역·친구 맛집·먹거리·필수·아이 동반), 「담을 날」을 한 번 고르고 ＋로 담기. 다른 날에 담긴 곳은 옮길지 먼저 묻습니다.
- **장소 상세**: 장소를 누르면 지도로 넘어가지 않고 사진·길찾기·담긴 날·도착 시간·메모·설명·가까운 후보를 보여 줍니다. 지도는 「지도에서 보기」나 핀으로 봅니다.
- **더보기**: 여행 고르기·새 여행·복제·여행 설정, 도시 전환, 공유 링크, 텍스트 저장, JSON 백업·가져오기, 인쇄.
- 지도 핀 말풍선에서도 담기·빼기·다른 날로가 됩니다. 이미 담긴 곳을 다시 담아도 순서가 바뀌지 않습니다.
- 어두운 모드는 기기 설정(prefers-color-scheme)을 따릅니다.
- 기존 `hkmo_planner_v1` localStorage 및 `#d1=...&d3=...` URL 이관

여행 데이터는 `hkmo_planner_v2`(상하이 `shanghai_planner_v2`)에 저장하고, 마지막에 본 날·담을 날·시트 높이 같은 화면 상태는 `hkmo_planner_view_v1`(상하이 `shanghai_planner_view_v1`)에 따로 둡니다. 화면 확인용으로 주소 뒤에 `?today=2026-10-24`(필요하면 `&now=14:05`)를 붙이면 그 날짜인 것처럼 오늘 화면을 볼 수 있습니다. 저장 데이터는 바뀌지 않습니다.

브라우저 저장소는 기기·브라우저·사이트 주소별로 구분됩니다. 다른 기기로 옮길 때 공유 URL이나 백업을 사용하세요. `file://` 주소는 다른 기기에서 열 수 없으므로 그 경우 백업을 사용합니다. 지도 타일·사진·외부 길찾기에는 인터넷이 필요합니다. 점선은 실제 도로 경로가 아닌 방문 순서입니다. 앱 내 MTR 노선은 기존의 일부 참고 노선을 유지합니다.

## 희수의 맛집

사용자가 제공한 대화 스크린샷 4장에 나온 상호 17곳을 `data.js`의 `HEESU_RESTAURANTS`에 정리했습니다. 개인적인 추천/취향 평가는 대화를 요약했으며 외부 평점으로 바꾸지 않았습니다. 실제 대화나 인물 사진은 앱에 포함하지 않습니다.

각 항목은 `name`, `englishName`, `menus`, `address`, `lat`, `lng`, `verdict`, `desc`, `branchNote`, `source`, `coordinateSource`, `checkedAt`를 갖습니다. 출처 링크는 지도 팝업에서도 확인할 수 있습니다.

- 찾기 → 친구 맛집 → 희수의 맛집(또는 윤환의 맛집) → 식당 핀 및 상호/메뉴 라벨 → 클릭하면 메뉴·주소·Google Maps 링크.
- 지도에 가까이 모인 라벨은 겹치지 않게 배치하며, 자리가 없으면 일부 라벨을 숨깁니다. 모든 핀은 유지되고 확대/검색하면 개별 장소를 확인할 수 있습니다.
- 정부 주소조회(https://www.als.gov.hk)에서 주소와 건물명을 대조한 건물 좌표입니다. 층·호수 및 실제 입구는 주소/외부 지도로 확인합니다.
- 지점이 명시되지 않은 체인은 확인 가능한 지점을 선택하고 `branchNote`에 그 사실을 표시했습니다.
- **라오장궤 동베이:** 대화의 침사추이 지점은 확인되지 않았습니다. 현재 주소가 확인된 타이콕추이 Cetus Square Mile점을 참고 위치로 표시하고 방문 지점 재확인 문구를 노출합니다. 과거 63 Tai Kok Tsui Road 주소를 쓰지 않습니다.
- **딤딤섬:** 대화의 침사추이 설명과 달리 주소가 확인되는 인근 조던점을 선택했습니다. 희수의 실제 방문 지점은 미확정입니다.
- **Fuel Coffee:** Fuel Espresso로 해석했으며 센트럴 IFC점을 선택했다고 명시합니다.
- **BaseHall:** 대화에는 입점 식당명이 없습니다. 푸드홀 위치를 표시하고 Return of Lemak의 공식 락사 판매 정보를 보조 설명으로 넣었습니다.
- **Sister Wah:** 스크린샷의 간판으로 식별. **Bakehouse**와 함께 추천 강도가 낮았던 사실을 보존합니다.
- **애문생:** 대화에 구체적인 메뉴명이 없어 홍콩관광청의 볶음요리 업종 설명을 표시합니다.

주소 확인일: 2026-09-14. 영업시간/가격은 임의로 확정하지 않습니다.

## 검증

`node --test test-planner.cjs test-cities.cjs`

순수 상태 로직 테스트: 기존 저장 순서 이관, 기존 공유 링크, 한글·메모·사용자 장소 공유 왕복, 날짜 이동, 잘못된 입력 방어, 오늘 날짜 계산(여행 전·중·후), 이미 담긴 장소 다시 담기(순서 유지·다른 날 이동).

실제 Chromium에서도 식당 핀과 팝업, 검색, Google Maps 링크, 일정 추가·정렬·시간·메모·방문체크·새로고침 복원, 일수 설정, 사용자 장소, 되돌리기, 공유 링크, 모바일 화면, 지도 라이브러리 실패 시 일정 편집을 검증했습니다.


## 상하이 여행
- `/shanghai/`에서 리재의 맛집 리스트 17곳과 산책 후보지를 볼 수 있습니다(찾기 → 친구 맛집). 화면 구성은 홍콩과 같습니다.
- 홍콩 `hkmo_planner_v2`와 상하이 `shanghai_planner_v2`는 별도로 저장됩니다. 백업·공유 링크의 city 값으로 서로 다른 도시의 데이터 혼입을 차단합니다. 기존 city 없는 홍콩 데이터는 그대로 읽습니다.
- 장소 보기와 일정 구간 길찾기는 고덕지도(Amap)로 연결됩니다. 중국어 이름·주소로 검색하며, 확인된 POI는 지점 상세 페이지를 엽니다.
- 자료: 사용자가 제공한 리재의 대화. 주소 출처는 각 장소 팝업에 연결했습니다(2026-09-14 확인). 12개 식당·음료 항목에 위치를 표시하고, 지점 미정 3곳 및 영업 재확인 2곳은 임의의 핀을 만들지 않았습니다. 홍이광장 3곳은 같은 건물 위치로 표시하며 팝업에서 다른 추천 매장으로 이동할 수 있습니다.
- 내부 지도는 OpenStreetMap, 외부 길찾기는 고덕지도입니다. 중국 현지 네트워크의 내장 지도 접근성은 별도로 확인해야 합니다. Leaflet은 상하이 페이지에 로컬 포함했습니다.
- Amap GCJ-02 좌표는 원본 보존 후 OSM용 WGS84로 변환합니다. 외부 길찾기에 원본 GCJ-02 좌표를 전달합니다. 직접 추가 장소와 숙소는 입력 좌표계를 선택할 수 있습니다.
- `vendor/coordtransform.js`: https://github.com/wandergis/coordtransform (MIT, 라이선스 동봉). Leaflet 1.9.4 라이선스도 동봉했습니다.
- 검증: `node --test test-planner.cjs test-cities.cjs`
